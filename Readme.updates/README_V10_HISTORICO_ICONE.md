# V10 — Histórico de corredores e ícone Android

- Histórico de supervisão dos 22 corredores com contagem de dias.
- Migração automática: usa a última batida finalizada quando `lastCheck` estiver ausente.
- Alertas: verde 0–6, amarelo 7–14, vermelho 15+.
- Corredores sem registro são identificados.
- Ícone pequeno monocromático e transparente para a barra de status do Android.
- Cache do Service Worker atualizado para V10.

Após publicar, feche e reabra o PWA ou limpe os dados/cache do site se o navegador continuar usando a versão anterior.
